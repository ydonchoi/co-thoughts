# Research Note Generation Engine v0.1 (가칭)

Status: HISTORICAL / SUPERSEDED

## Pipeline
1. Detect Research Objects
2. Decompose
3. Extract Research Question
4. Classify Research Purpose
5. Classify Question Operators
6. Classify Other Axes
7. Select Document Type
8. Instantiate TOC
9. Map Evidence
10. SARA Verify
11. Assign Epistemic State
12. Map Relations

Optional:
13. Synthesize
14. Re-verify

## Historical Limitation
The original linear pipeline classified purpose/document type before evidence and SARA. Later stress testing showed that evidence can change classification. This led to v0.2 provisional classification and final reclassification.

## Core Distinctions
Conversation ≠ Research Note
Purpose ≠ Method
Purpose ≠ Document Type
Claim ≠ Evidence
Evidence ≠ Verification
Verification ≠ Agreement
Research Note ≠ Evidence
