# Research Note Taxonomy v0.2 (가칭)

Status: HISTORICAL / RECONSTRUCTED / SUPERSEDED

> Reconstructed from the project's recorded taxonomy-development decisions; not a byte-for-byte historical snapshot.

## Main Changes from v0.1

1. Research Purpose was expanded from broad categories into a three-level hierarchy: major category → subcategory → specific subtype.
2. Purpose was explicitly separated from Question Operator, Research Design, Method, Evidence/Source, Knowledge Domain, R&D Orientation, Claim/Epistemic Status, Knowledge Product, and Document Type.
3. The taxonomy was normalized from recurring academic research-purpose classifications rather than presented as a universally accepted single taxonomy.
4. Taxonomy provenance and an axis-audit requirement were introduced as design requirements.

## Purpose Structure

### R1 탐색
- phenomenon exploration
- concept exploration
- structure exploration
- problem exploration
- hypothesis/model generation

### R2 기술
- characteristic description
- composition/classification description
- distribution description
- change description

### R3 설명
- relationship explanation
- influence/causal explanation
- mechanism explanation
- process/system explanation

### R4 예측
- state prediction
- trend prediction
- outcome prediction
- conditional prediction

### R5 평가
- effect evaluation
- performance evaluation
- impact evaluation
- process evaluation
- improvement/decision evaluation

## Structural Principle

Purpose ≠ Method.
Purpose ≠ Document Type.
Claim ≠ Evidence.
Evidence ≠ Verification.

## Supersession

Superseded by v0.3, which formalized primary/secondary purpose, taxonomy provenance, and axis-audit priority.
