# T53 — Cross-Document-Type AI Disclosure Regression Test v0.1

Status: **PASS — CROSS-TYPE AI DISCLOSURE CONTRACT CONSISTENT / NO ARCHITECTURE EXPANSION**

## 1. Purpose
T53 tests whether the T51/T52 AI authorship disclosure and provenance rules hold across all current Research Note Document Types D1–D9 and lifecycle outcomes NEW, REVISION, EXTENSION, NO_CHANGE, and BLOCKED.

AI disclosure is treated as a cross-cutting provenance/presentation layer, not a Document Type, epistemic state, or new knowledge object.

## 2. Baseline Rules
Every Research Note generated by the Research Note Engine must carry:
1. a visible artifact-level AI disclosure;
2. generation provenance;
3. structured disclosure through the existing `confession_report` representation where available;
4. human-review status;
5. local attribution only when sufficiently supported.

Canonical visible marker: **AI-generated / AI-structured Research Note**

The marker identifies AI participation in generating/structuring the artifact. It does not claim that every proposition, idea, source statement, or token originated from AI.

## 3. Cross-Type Test Matrix

| Type | Primary AI risk | Required attribution behavior | Result |
|---|---|---|---|
| D1 Exploration | AI-generated hypothesis mistaken for human/verified finding | distinguish user question, AI exploration, generated hypothesis | PASS |
| D2 Description / Current State | AI description mistaken for observed fact | preserve observation/source provenance | PASS |
| D3 Concept Analysis | AI-selected conceptualization mistaken for authoritative definition | preserve source/user attribution and working interpretation | PASS |
| D4 Relation / Impact | AI causal wording mistaken for established causality | preserve evidence and verification provenance | PASS |
| D5 Mechanism / Process | AI mechanism generation mistaken for established mechanism | identify Transformation and epistemic state | PASS |
| D6 Prediction | AI forecast mistaken for future fact | preserve model/condition provenance and uncertainty | PASS |
| D7 Evaluation | AI judgment mistaken for human normative judgment | preserve criteria provenance and human decision role | PASS |
| D8 Literature / Evidence Synthesis | AI synthesis mistaken for source consensus | preserve source Claims, disagreement, and synthesis Transformation | PASS |
| D9 Integrated Synthesis | AI integration mistaken for verified integrated theory | preserve source-note provenance, integration Transformation, independent Claim/SARA | PASS |

## 4. Common Cross-Type Invariants
All D1–D9 preserve:
- AI disclosure ≠ epistemic state;
- AI authorship ≠ Evidence;
- AI-generated text ≠ VERIFIED Claim;
- AI structuring ≠ Verification;
- source-derived content ≠ AI-originated content;
- human-authored input ≠ automatically verified;
- persistence ≠ verification;
- D9 PROMOTED ≠ authorship or verification.

Result: **PASS**

## 5. Lifecycle Regression Matrix

### NEW
A newly generated Research Note receives the visible AI disclosure and provenance chain. **PASS**

### REVISION
The artifact retains prior AI provenance. New AI-generated analysis adds provenance; Revision Event and historical state are preserved. **PASS**

### EXTENSION
Additional material retains AI provenance where generated/structured by AI. Human/source contributions remain distinguishable where reliably known. **PASS**

### NO_CHANGE
No new artifact is generated; existing disclosure remains unchanged. **PASS**

### BLOCKED
A candidate generated while persistence is unavailable still carries disclosure and is not represented as persisted. **PASS**

## 6. Human Post-Editing Regression

### H1 — Minor Edit
Human corrects wording without changing substantive structure. Artifact remains AI-generated/structured; token-level attribution is unnecessary. **PASS**

### H2 — Material Section Edit
Human substantially rewrites a section. Artifact-level AI disclosure remains; material human editing may be recorded as A4; the final text is not falsely represented as wholly AI-generated. **PASS**

### H3 — Human Replaces Analytical Conclusion
Earlier AI-analysis provenance remains. The new human-authored conclusion is not attributed to AI without basis; epistemic state is independently re-evaluated through SARA. **PASS**

## 7. Type-Specific Attribution Controls
- **D1:** AI-generated hypotheses remain hypotheses unless independently supported and verified.
- **D2:** Distinguish observed/source-derived information from AI exposition.
- **D3:** An AI-selected working conceptualization is not an external author's definition.
- **D4:** AI-generated causal language must not exceed the underlying Evidence.
- **D5:** Mechanism language stays tentative when support is insufficient.
- **D6:** Predictions retain model, condition, uncertainty, and falsification/update provenance.
- **D7:** Evaluation preserves criteria provenance and human decision authority.
- **D8:** Synthesis must not collapse source disagreement into consensus.
- **D9:** Integration preserves source-note Claims/Evidence and independently evaluates new integrated Claims.

All controls: **PASS**

## 8. Failure Conditions
T53 fails if a Document Type suppresses mandatory AI disclosure; a lifecycle transition removes provenance; human edits erase artifact-level provenance; source content is relabeled AI-originated; AI synthesis is relabeled human-originated without basis; AI-generated Claims are epistemically upgraded merely because AI generated them; D9 inherits source verification automatically; BLOCKED persistence removes disclosure; or Document Type is used as an authorship proxy.

No such failure was identified in the controlled cross-type test.

## 9. Architecture Decision
**RETAIN CURRENT ARCHITECTURE.**

AI authorship disclosure remains a cross-cutting layer implemented through:
1. visible artifact marker;
2. generation provenance;
3. `confession_report`;
4. optional local attribution where provenance supports it.

No new Document Type, Research Object, Claim, Evidence, Verification, Branch/Merge entity, or Notion database is justified.

## 10. Result
**T53 = PASS**

The AI disclosure model is structurally compatible with all current D1–D9 types and tested lifecycle outcomes.

> **Every AI-generated/AI-structured Research Note discloses AI participation at the artifact level; local authorship is distinguished only where provenance supports the distinction.**

## 11. Validation Boundary
T53 is a controlled cross-type regression specification, not a statistical study of generated outputs. It does not establish population-level attribution accuracy, legal sufficiency, institutional compliance, or reliable automated sentence-level authorship detection.

## 12. Next Phase
T53 closes cross-document-type semantic regression for AI disclosure. Further architecture work should not add another authorship entity unless implementation testing demonstrates a concrete need.

Next implementation-oriented candidate: **T54 — AI Disclosure Rendering / Actual Research Note Output Test**, inspecting visible marker placement, `confession_report`, provenance block, D1–D9 compatibility, human-review status, BLOCKED persistence, and absence of epistemic inflation.

## 13. Boundary
This is a project-level operational test and specification, not an established academic, legal, or industry standard. The human remains the final epistemic decision authority.
