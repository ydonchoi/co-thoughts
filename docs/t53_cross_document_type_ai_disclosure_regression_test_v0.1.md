# T53 — Cross-Document-Type AI Disclosure Regression Test v0.1

Status: **PASS — CROSS-TYPE AI DISCLOSURE CONTRACT CONSISTENT / NO ARCHITECTURE EXPANSION**

## 1. Purpose

T53 tests whether the T51/T52 AI authorship disclosure and provenance rules remain valid across all current Research Note Document Types D1–D9 and across lifecycle outcomes:

- NEW
- REVISION
- EXTENSION
- NO_CHANGE
- BLOCKED

The test treats AI disclosure as a cross-cutting provenance/presentation layer rather than as a Document Type, epistemic state, or new knowledge object.

## 2. Baseline Rules

Every Research Note generated by the Research Note Engine must carry:

1. a visible artifact-level AI disclosure;
2. generation provenance;
3. structured disclosure through the existing confession_report representation where available;
4. human-review status;
5. local attribution only when sufficiently supported.

Canonical visible marker:

**AI 작성·구조화 연구노트**

The marker identifies AI participation in artifact generation/structuring. It does not claim that every proposition, idea, source statement, or token originated from AI.

## 4. Common Cross-Type Invariants

All D1–D9 must preserve:

- AI disclosure ≠ epistemic state;
- AI authorship ≠ Evidence;
- AI-generated text ≠ VERIFIED Claim;
- AI structuring ≠ Verification;
- source-derived content ≠ AI-originated content;
- human-authored input ≠ automatically verified;
- persistence ≠ verification;
- D9 PROMOTED ≠ authorship or verification.

Result: **PASS**

## 5. Lifecycle Regression Matrix

### NEW

A newly generated Research Note receives the visible AI disclosure and provenance chain.

Result: **PASS**

### REVISION

The existing artifact retains prior AI provenance. New AI-generated analysis is added as new provenance, while Revision Event and historical state are preserved.

Result: **PASS**

### EXTENSION

Additional material retains AI provenance where AI generated/structured it. Human/source contributions remain distinguishable where reliably known.

Result: **PASS**

### NO_CHANGE

No new artifact is generated. Existing disclosure remains unchanged.

Result: **PASS**

### BLOCKED

A candidate generated while persistence is unavailable still carries AI disclosure. The candidate is not represented as persisted.

Result: **PASS**

## 6. Human Post-Editing Regression

Three cases were tested conceptually across D1–D9:

### H1 — Minor edit

Human corrects wording without changing substantive structure.

Expected:
- artifact remains AI-generated/structured;
- human edit need not be represented at token level.

Result: **PASS**

### H2 — Material section edit

Human substantially rewrites a section.

Expected:
- artifact-level AI disclosure remains;
- material human editing may be recorded as A4;
- final text is not falsely represented as wholly AI-generated.

Result: **PASS**

### H3 — Human replaces analytical conclusion

Human changes a substantive conclusion.

Expected:
- AI provenance of the earlier analysis remains;
- new human-authored conclusion is not attributed to AI without basis;
- epistemic state is independently re-evaluated through SARA.

Result: **PASS**

## 7. Type-Specific Attribution Controls

### D1

AI-generated hypotheses must remain hypotheses unless independently supported and verified.

### D2

AI-written descriptions must retain the distinction between observed/source-derived information and AI exposition.

### D3

AI-selected working conceptualization must not be presented as an external author's definition.

### D4

AI-generated causal language must not outrun the underlying evidence.

### D5

AI-generated mechanism language must remain explicitly tentative when support is insufficient.

### D6

AI-generated predictions must retain model, condition, uncertainty, and falsification/update provenance.

### D7

AI-generated evaluation judgment must not erase the provenance of evaluation criteria or human decision authority.

### D8

AI synthesis must not collapse source disagreement into consensus.

### D9

AI integration must preserve source-note Claims/Evidence and independently evaluate newly integrated Claims.

All controls: **PASS**

## 8. Failure Conditions

T53 fails if any of the following occur:

- a Document Type suppresses mandatory AI disclosure;
- a lifecycle transition removes AI provenance;
- human edits erase artifact-level AI provenance;
- source content is relabeled as AI-originated;
- AI synthesis is relabeled as human-originated without basis;
- AI-generated Claims receive epistemic upgrades solely because AI generated them;
- D9 integration inherits source verification automatically;
- BLOCKED persistence removes the disclosure;
- document type is used as a proxy for authorship.

No such failure was identified in the controlled cross-type test.

## 9. Architecture Decision

**RETAIN CURRENT ARCHITECTURE.**

AI authorship disclosure remains a cross-cutting layer implemented through:

1. visible artifact marker;
2. generation provenance;
3. confession_report;
4. optional local attribution where provenance supports it.

No new:

- Document Type;
- Research Object;
- Claim;
- Evidence;
- Verification;
- Branch/Merge entity;
- Notion database

is justified.

## 10. Result

**T53 = PASS**

The AI disclosure model is structurally compatible with all current D1–D9 Document Types and the tested lifecycle outcomes.

The central rule is stable:

> **Every AI-generated/AI-structured Research Note discloses AI participation at the artifact level; local authorship is distinguished only where provenance supports the distinction.**

## 11. Validation Boundary

T53 is a controlled cross-type regression specification, not a statistical study of generated outputs.

It does not establish:

- population-level attribution accuracy;
- legal sufficiency;
- institutional compliance;
- reliable automated sentence-level authorship detection.

Those remain context-dependent.
