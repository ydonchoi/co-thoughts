# Research Note Document Types v0.1 (가칭)

Status: **PROJECT PROPOSAL**

Different document types use different fixed structures. A single universal research-note TOC is not used.

## D1 탐색 연구노트
대상/목적 → 현재 지식 → 범위 → 현상/문제 → 패턴/단서 → 잠정 구조 → 경쟁 해석 → 탐색 결과 → 생성 가설/모델 → 미지 영역 → 후속 질문

## D2 기술·현황 연구노트
대상/목적/범위 → 관찰·분류 기준 → 특성 → 구성·유형 → 분포 → 변화 → 패턴·예외 → 요약 → 한계·미지

## D3 개념 분석 연구노트
개념/질문 → 배경 → 주요 정의 → 정의 차이 → 핵심 속성 → 경계 → 인접 개념 → 구성/차원 → 개념 관계 → 경쟁적 개념화 → 채택 개념화 → 범위/한계 → 후속 질문

## D4 관계·영향 분석 연구노트
질문 → 대상/변수/개념 → 기존 설명 → 관계 구조 → 방향/형태 → 비교/차이 → 영향 가능성 → 인과 해석 → 대안 설명 → 반증/반대근거 → 경계조건 → 검증 상태 → 결론

## D5 메커니즘·과정 분석 연구노트
질문 → 대상 → 기존 설명 → 구성요소 → 관계 구조 → 과정 → 잠정 메커니즘 → 매개/조절/피드백 → 대안 → 근거 → 반대근거 → 경계 → 검증 상태 → 결론/후속

## D6 예측 연구노트
예측 질문 → 대상/기간 → 현재 상태 → 근거 → 변수/조건 → 모델/논리 → 기준 시나리오 → 대안 → 임계조건 → 불확실성 → 검증/반증 조건 → 결과 → 업데이트 조건

## D7 평가 연구노트
대상 → 목적 → 평가기준 → 기준 근거 → 현재 상태 → 효과/성과/영향 → 과정 → 대안 → 긍정/부정 결과 → 불확실성/한계 → 판단 → 개선/의사결정 함의

## D8 문헌·근거 종합 연구노트
검토 질문 → 범위/포함 기준 → 검색/선별 → 개념 → 연구 흐름 → 주장 → 근거 비교 → 합의 → 불일치/논쟁 → 방법론 차이 → 근거 강도/한계 → 종합 → 연구 공백 → 후속 질문

Review Type metadata:
Narrative Review, Systematic Review, Scoping Review, Integrative Review, Meta-analysis, Qualitative Synthesis, Other.

## D9 통합·종합 연구노트
대상 note → 통합 질문 → 각 note 핵심 주장 → 공통점 → 긴장/차이 → support relations → conflict → 통합 가능한 구조 → 통합 설명/모델 → 통합 근거 → 한계 → 미해결 문제 → 새 질문

D9는 요약본이 아니라 **검증 가능한 새로운 통합 구조**를 목표로 한다.

## Common Metadata

Note ID, title, source conversation, related notes, document type, taxonomy code, purpose, operator, domain, design, method, evidence type, R&D orientation, knowledge product, claim, premise, evidence, epistemic state, uncertainty, boundary, counter-evidence, verification state, revision history.

Research Note ≠ Evidence.
