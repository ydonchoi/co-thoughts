# Research Note Taxonomy v0.3 (provisional project taxonomy)

Status: **PROJECT PROPOSAL / NORMALIZED TAXONOMY**

This is a project-normalized classification. It is not claimed to be a single, universally accepted academic taxonomy.

## 1. Research Purpose

### R1 Exploration

- R1.1 Phenomenon exploration
  - R1.1.1 Discover a new phenomenon
  - R1.1.2 Explore phenomenon characteristics
  - R1.1.3 Explore the scope of a phenomenon
- R1.2 Concept exploration
  - R1.2.1 Explore concept meaning
  - R1.2.2 Explore concept boundaries
  - R1.2.3 Explore relations between concepts
- R1.3 Structure exploration
  - R1.3.1 Explore components
  - R1.3.2 Explore provisional relations
  - R1.3.3 Explore provisional structures
- R1.4 Problem exploration
  - R1.4.1 Explore problem composition
  - R1.4.2 Explore problem scope
  - R1.4.3 Explore the problem's key issues
- R1.5 Hypothesis/model generation
  - R1.5.1 Generate a provisional explanation
  - R1.5.2 Generate a hypothesis
  - R1.5.3 Generate a conceptual model

### R2 Description

- R2.1 Describe characteristics
- R2.2 Describe composition/classification
- R2.3 Describe distributions
- R2.4 Describe changes

### R3 Explanation

- R3.1 Explain relations
- R3.2 Explain impacts/causality
- R3.3 Explain mechanisms
- R3.4 Explain processes/systems

### R4 Prediction

- R4.1 Predict a state
- R4.2 Predict a trend
- R4.3 Predict an outcome
- R4.4 Make a conditional prediction

### R5 Evaluation

- R5.1 Evaluate effectiveness
- R5.2 Evaluate performance
- R5.3 Evaluate impact
- R5.4 Evaluate a process
- R5.5 Evaluate improvement/decision options

## 2. Separate Axes

Do not create new taxonomies when an established axis or metadata field already captures the distinction.

Separate axes:
- Question Operator
- Research Design
- Method
- Evidence/Source
- Knowledge Domain
- R&D Orientation
- Claim/Epistemic Status
- Knowledge Product
- Document Type
- Review Type
- Synthesis Operation

Purpose ≠ Method. Purpose ≠ Document Type. Claim ≠ Evidence.

## 3. Primary / Secondary Purpose

Primary Purpose: maximum 1.

Secondary Purpose: zero or more.

If a secondary purpose has an independent research question, evidence structure, and conclusion, create a separate Research Object rather than hiding its independence in metadata.

## 4. Taxonomy Provenance

For each adopted/transformed item record:

Taxonomy ID
→ Source
→ Original Classification
→ Classification Axis
→ Project Interpretation
→ Adopted / Rejected / Transformed
→ Transformation Reason
→ Evidence
→ Version
→ Status
