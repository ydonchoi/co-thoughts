# Research Note Document Types v0.1 (provisional project specification)

Status: **PROJECT PROPOSAL**

Different document types use different fixed structures. There is no single universal research-note table of contents.

## D1 Exploratory Research Note
Object/purpose → Current knowledge → Scope → Phenomenon/problem → Patterns/clues → Provisional structure → Competing interpretations → Exploration results → Generated hypothesis/model → Unknowns → Follow-up questions

## D2 Descriptive / Current-State Research Note
Object/purpose/scope → Observation/classification criteria → Characteristics → Composition/types → Distribution → Change → Patterns/exceptions → Summary → Limitations/unknowns

## D3 Concept Analysis Research Note
Concept/question → Background → Major definitions → Differences among definitions → Core attributes → Boundaries → Adjacent concepts → Components/dimensions → Concept relations → Competing conceptualizations → Adopted conceptualization → Scope/limitations → Follow-up questions

## D4 Relation / Impact Analysis Research Note
Question → Objects/variables/concepts → Existing explanations → Relational structure → Direction/form → Comparisons/differences → Potential impacts → Causal interpretation → Alternative explanations → Falsification/counter-evidence → Boundary conditions → Verification status → Conclusion

## D5 Mechanism / Process Analysis Research Note
Question → Object → Existing explanations → Components → Relational structure → Process → Provisional mechanism → Mediation/moderation/feedback → Alternatives → Evidence → Counter-evidence → Boundaries → Verification status → Conclusion/follow-up

## D6 Predictive Research Note
Prediction question → Object/time horizon → Current state → Evidence → Variables/conditions → Model/logic → Baseline scenario → Alternatives → Threshold conditions → Uncertainty → Verification/falsification conditions → Outcome → Update conditions

## D7 Evaluation Research Note
Object → Purpose → Evaluation criteria → Basis for criteria → Current state → Effectiveness/performance/impact → Process → Alternatives → Positive/negative outcomes → Uncertainty/limitations → Judgment → Improvement/decision implications

## D8 Literature / Evidence Synthesis Research Note
Review question → Scope/inclusion criteria → Search/screening → Concepts → Research streams → Claims → Evidence comparison → Agreement → Disagreement/debate → Methodological differences → Evidence strength/limitations → Synthesis → Research gaps → Follow-up questions

Review Type metadata:
Narrative Review, Systematic Review, Scoping Review, Integrative Review, Meta-analysis, Qualitative Synthesis, Other.

## D9 Integrated / Synthesis Research Note
Target notes → Integration question → Key claims from each note → Commonalities → Tensions/differences → Support relations → Conflicts → Integrable structure → Integrated explanation/model → Integrated evidence → Limitations → Unresolved problems → New questions

D9 aims to produce a **new, verifiable integrated structure**, not merely a summary.

## Common Metadata

Note ID, title, source conversation, related notes, document type, taxonomy code, purpose, operator, domain, design, method, evidence type, R&D orientation, knowledge product, claim, premise, evidence, epistemic state, uncertainty, boundary, counter-evidence, verification state, revision history.

Research Note ≠ Evidence.
