# Research Note Taxonomy v0.2 (provisional project term)

Status: HISTORICAL / RECONSTRUCTED / SUPERSEDED

> Reconstructed from recorded taxonomy-development decisions; not a byte-for-byte historical snapshot.

## Main Changes from v0.1
1. Research Purpose expanded from broad categories into a three-level hierarchy: major category → subcategory → specific subtype.
2. Purpose explicitly separated from Question Operator, Research Design, Method, Evidence/Source, Knowledge Domain, R&D Orientation, Claim/Epistemic Status, Knowledge Product, and Document Type.
3. The taxonomy was normalized from recurring academic Research Purpose classifications rather than presented as a universally accepted single taxonomy.
4. Taxonomy provenance and an axis-audit requirement were introduced as design requirements.

## Purpose Structure

### R1 Exploration
- phenomenon exploration
- concept exploration
- structure exploration
- problem exploration
- hypothesis/model generation

### R2 Description
- characteristic description
- composition/classification description
- distribution description
- change description

### R3 Explanation
- relationship explanation
- influence/causal explanation
- mechanism explanation
- process/system explanation

### R4 Prediction
- state prediction
- trend prediction
- outcome prediction
- conditional prediction

### R5 Evaluation
- effect evaluation
- performance evaluation
- impact evaluation
- process evaluation
- improvement/decision evaluation

## Structural Principle
Purpose ≠ Method.  
Purpose ≠ Document Type.  
Claim ≠ Evidence.  
Evidence ≠ Verification.

## Supersession
Superseded by v0.3, which formalized primary/secondary purpose, taxonomy provenance, and axis-audit priority.
