# Research Note Generation Engine v0.1 (provisional project term)

Status: HISTORICAL / SUPERSEDED

## Pipeline
1. Detect Research Objects
2. Decompose
3. Extract Research Question
4. Classify Research Purpose
5. Classify Question Operators
6. Classify Other Axes
7. Select Document Type
8. Instantiate Table of Contents
9. Map Evidence
10. Verify with SARA
11. Assign Epistemic State
12. Map Relations

Optional:
13. Synthesize
14. Re-verify

## Historical Limitation
The original linear pipeline classified purpose and document type before Evidence and SARA. Later stress testing showed that Evidence can change classification. This led to provisional classification in v0.2 and final reclassification.

## Core Distinctions
Conversation ≠ Research Note  
Purpose ≠ Method  
Purpose ≠ Document Type  
Claim ≠ Evidence  
Evidence ≠ Verification  
Verification ≠ Agreement  
Research Note ≠ Evidence
