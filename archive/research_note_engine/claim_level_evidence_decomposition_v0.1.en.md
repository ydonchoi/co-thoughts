# Claim-Level Evidence Decomposition Rule v0.1 (provisional project term)

Status: HISTORICAL / PROJECT PROPOSAL

## Principle
An Integrated Model is not a single Claim.

Decompose it into:
- C1: component claim
- C2: relation claim
- C3: condition claim
- C4: result claim
- C5: integrated claim

Separate a claim when it can be evaluated independently for truth, requires independent evidence, can have a different epistemic state or counter-evidence, or can be independently retained or rejected.

## Evidence Roles
SUPPORT, CONTRADICT, CONTEXT, ILLUSTRATE, BACKGROUND.

Inference, project interpretation, and model proposal are provenance layers, not evidence.

## Core Rule
Component claims may be verified while the integrated model remains a HYPOTHESIS.

Never automatically promote the integrated model to VERIFIED.
