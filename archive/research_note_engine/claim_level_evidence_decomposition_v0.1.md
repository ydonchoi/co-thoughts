# Claim-Level Evidence Decomposition Rule v0.1 (가칭)

Status: HISTORICAL / PROJECT PROPOSAL

## Principle
An Integrated Model is not a single Claim.

Decompose:
- C1 component claim
- C2 relation claim
- C3 condition claim
- C4 result claim
- C5 integrated claim

Separate a claim when it is independently truth-evaluable, needs independent evidence, can have different epistemic state/counterevidence, or can be independently retained/rejected.

## Evidence Roles
SUPPORT, CONTRADICT, CONTEXT, ILLUSTRATE, BACKGROUND.

Inference, project interpretation, and model proposal are provenance layers, not evidence.

## Core Rule
Component claims may be verified while the integrated model remains HYPOTHESIS.

Never auto-promote the integrated model to VERIFIED.
