# Research Note Reproducibility Verification Protocol v0.1 (provisional project term)

Status: HISTORICAL / PROJECT PROPOSAL

## Levels
- Level 1 — Decision Reproducibility
- Level 2 — Research Object Boundary Reproducibility
- Level 3 — Classification Reproducibility
- Level 4 — Provenance Reproducibility
- Level 5 — End-to-End Reproducibility

## Test
Process the same source independently using different orders or approaches and compare:
- Primary Purpose
- Question Operator
- Document Type
- Epistemic State
- Split/merge decision
- Object boundaries

## RN-15 Result
Two independent passes matched on core decisions:
R3 explanation; mechanism/process/condition; D5; HYPOTHESIS; no split.

Object naming/granularity differed. This was treated as boundary ambiguity rather than classification failure.

Verdict:
- Level 1: PASS
- Level 2: CONDITIONAL PASS

## Consequence
A Research Object Boundary Rule was required and incorporated into the generation engine.
